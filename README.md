# Sadar Uang

Sadar Uang is an Android-based personal finance application designed to help users record, manage, and analyze their daily expenses and monthly budgets.

## Overview

Managing personal expenses can be difficult when financial transactions are recorded manually or scattered across different applications.

Sadar Uang was developed to provide a simple and organized way for users to record expenses, monitor their monthly budget, and understand their spending through financial summaries and analytics.

## Features

- User authentication
- Expense tracking
- Monthly expense management
- Budget management
- Expense history
- Financial dashboard
- Expense analytics
- Receipt image upload
- Monthly and yearly expense summary
- Calendar-based expense management
- PDF export
- Dark mode

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Room Database
- Material Design
- Gradle

## Architecture

The application is developed using a structured Android architecture to separate the user interface, data management, and application logic.

Main components include:

- UI layer
- Data layer
- Local database
- Application logic
